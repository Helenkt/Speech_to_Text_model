# Speech_to_Text_model

Faster Whisper Medium model files for local Vietnamese and English speech recognition.

## Download

Download `whisper-medium-model-only.zip` from the repository's Releases page and extract it into one directory.

The package contains:

- `model.bin`
- `config.json`
- `tokenizer.json`
- `vocabulary.txt`
